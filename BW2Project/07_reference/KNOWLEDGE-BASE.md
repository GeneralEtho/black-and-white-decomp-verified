# Black & White 2 knowledge base: how the game is built and runs

One document, by subsystem. Every entry is one line: an ID, the fact, its source, and a status.

**Status words**
- **verified**: we measured it ourselves and the entry names a measurement script or check run in this repo.
- **claimed**: a credible source said it (a spec, a report, a chat message) and we have not checked it with a script. Where a hand check was done, the entry says so.
- **contradicted**: two sources disagree. Both are recorded. No winner is picked without evidence.

**Source forms.** Paths start at the repo root. A Discord source is channel, date, author handle. Credit goes to the handle named; the chat export is `BW2Project/01_incoming/discord/`. Nothing here copies game bytes, keys or personal data.

**Run a measurement again.** The scripts live in `BW2Project/05_work/tools/measure/` (see its README.md). Run with `python3 -I`.

**Addresses.** This file does not list addresses. They go in `community-anchors.json` (task T11, not built yet) and the name map.
