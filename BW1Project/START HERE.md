# Black & White 1 Project

Companion to BW2Project. Same layout, same rules. BW1 is the easier, better-mapped game:
openblack already has a matching decompilation (bw1-decomp) and a new engine (openblack),
so here we mostly LEARN from and BUILD ON community work rather than start from zero.

## Why it's useful for BW2
BW2 is the same engine four years later. Class names recovered for BW1 are hypotheses to test against BW2's white.exe.

## Folders
| Folder | What goes in it | Who touches it |
| --- | --- | --- |
| 01_incoming | Your downloads and disc images | You drop files in; the AI sorts them |
| 02_game | The playable install | You install and play-test here |
| 03_vault | Untouched originals + fingerprints. The answer key | Nobody, once filled |
| 04_checks | PASS/FAIL tests | Only you approve changes |
| 05_work | Everything the AI builds | The AI |
| 06_reports | Plain-English results | The AI writes, you read |
| 07_reference | Community docs and tools | The AI fetches |
| 08_notes | Progress and decisions | Both |

## Golden rules
- Never edit anything in 03_vault.
- A FAIL is fixed by fixing the work, never by changing the check.
